# Skeleton Searcher 1.5.1（第六版）

适用于 **Minecraft Java Edition 1.21.11 + Fabric** 的纯客户端区域高亮模组。

## 主要改动

本版重写了高亮渲染器，重点改善大范围或高亮方块较多时的卡顿，并加入真正由渲染管线控制的“隔墙透视”开关。

### 性能优化

- 将搜索空间拆分为 `16×16×16` 区段，并缓存每个区段的 CPU 网格。
- 玩家跨区段移动时复用仍然有效的旧区段，只计算新进入范围或 LOD 变化的区段。
- 在逐点扫描前先做球体与区段包围盒剪枝，直接跳过不可能包含结果的区段。
- 球壳只生成暴露面，不再为相邻高亮方块生成彼此接触的内部面。
- 根据玩家距离自动使用 `1 / 2 / 4 / 8` 格采样步长：近处保留精度，远处降低面数。
- 半透明方块模式只在内部保留稀疏体积标记，其余部分沿用暴露面网格，避免恢复旧版海量完整立方体。
- 网格在结果变化时才生成并上传到持久化 GPU 顶点缓冲区；正常帧直接绘制已上传网格，不再每帧重新创建所有顶点。
- 透明度通过渲染统一变量实时调整，不重新计算几何，也不重新上传顶点网格。
- 保留 `300000` 个可见面的安全上限，超过时截断并在日志中提示降低渲染距离。

## 隔墙透视

进入 `O → 显示设置`，点击：

```text
隔墙透视：开启 / 关闭
```

- **开启**：使用关闭深度测试、关闭深度写入的专用渲染管线，高亮可以隔着实体方块看见。
- **关闭**：使用正常深度测试，高亮会被墙壁、地面等方块遮挡。
- 开关不会重新计算网格，点击后下一帧直接切换。
- 新配置默认开启；旧配置首次由本版读取时也默认开启。

## 条件计算规则

- 第 1、2 个条件只记录并计算，不进行世界渲染。
- 从第 3 个条件开始渲染最终结果。
- 普通档位取共同交集。
- `>250` 为差集条件：从此前重合区域中减去以输入坐标为球心、半径 250 的实心球。
- `>250` 不能作为第一个条件，必须先存在同维度的普通球体。
- `>250` 添加时不执行“无共同区域则拒绝”检查。
- 后续普通档位仍会在最终结果为空时拒绝，并提示“已超出区域”。

## 条件档位与文字颜色

1. `>250`：白色
2. `250–150`：浅红
3. `150–100`：深蓝
4. `100–50`：黄色
5. `50–25`：亮绿
6. `50–0`：亮蓝

## 渲染样式

在 `O → 显示设置` 中切换：

- **球壳**：只显示最终结果区域的边界。
- **半透明方块**：显示边界，并在区域内部加入稀疏半透明方块以表达体积。

两种样式都支持隔墙透视开关。

## 快捷键

- `O`：打开设置页面。
- `Delete`：清除全部条件和高亮缓存。

可在 `选项 → 控制 → 按键绑定 → Skeleton Searcher` 中修改。

## 渲染距离

设置范围为 `24–300` 格。渲染距离越大，需要处理的区段仍然越多；虽然本版已加入缓存、剪枝和 LOD，但复杂交集下仍建议按实际需要设置，通常先从 `96–160` 格测试。

## 配置文件

```text
.minecraft/config/skeleton_searcher.json
```

新增字段：

```json
"throughWalls": true
```

## 构建

项目使用：

- Java 21
- Gradle 9.2.0
- Fabric Loom 1.14.10
- Fabric Loader 0.19.3
- Fabric API 0.141.4+1.21.11

将解压后的项目内容上传到 GitHub 仓库根目录。GitHub Actions 构建成功后，在该次运行的 `Summary → Artifacts` 下载并解压：

```text
skeleton-searcher-1.5.1.jar
```

不要把 `-sources.jar` 放进 `mods` 文件夹。
